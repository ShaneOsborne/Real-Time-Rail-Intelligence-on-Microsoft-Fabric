# Rayfin app starter – map + "chat with the network" (Lab 11)

This folder is **not** a complete app. Rayfin projects are generated by the Rayfin CLI, so you scaffold a project
**next to this repo** (not inside it) and copy the overlay files from `rayfin-starter/` into it. See
[Lab 11](../docs/labs/11-rayfin-app.md) for the full steps, where to find each value, and troubleshooting.

> Status (Oct 2026, Rayfin 1.36.2): Fabric Apps is **preview**. **New Kusto connectors can't be added** in 1.36.2
> (`connector add --type kusto` → *not available in this release*), so this starter reads the Eventhouse through a
> **function** with a delegated `AudienceType.Kusto` token instead. Functions aren't available in every tenant/region.

## Steps

```bash
# From the folder ABOVE this repo
npm create @microsoft/rayfin@latest -- rail-app --workspace rail-fabric-rti   # workspace NAME; choose the default (React) template
cd rail-app
npx rayfin login
npx rayfin functions init

cp -r ../rail-fabric-rti/app/rayfin-starter/src/* src/
#   merge ../rail-fabric-rti/app/rayfin-starter/rayfin/functions/src/function_app.ts into rayfin/functions/src/function_app.ts
#   set KUSTO_QUERY_URI, KQL_DATABASE, FOUNDRY_PROJECT_ENDPOINT, FOUNDRY_AGENT_NAME at the top of it
#   render <RailApp /> from src/App.tsx

npx rayfin up --dry-run
npx rayfin up
npx rayfin up status
```

## What each overlay file does

| File | Purpose |
|---|---|
| `src/services/rayfinClient.ts` | `RayfinClient<AppSchema, AppFunctionsSchema>` – typed access to the two functions |
| `src/features/network/loadSnapshot.ts` | Calls `getNetworkSnapshot` and maps rows to train positions |
| `src/features/network/NetworkMap.tsx` | Dependency-free SVG map of GB, coloured by delay, refreshes every 30 s |
| `src/features/chat/ChatPanel.tsx` | Chat UI calling `client.functions.askRailAgent.invoke()` |
| `rayfin/functions/src/function_app.ts` | `getNetworkSnapshot` (delegated `AudienceType.Kusto` → KQL REST `/v1/rest/query`, fixed query) and `askRailAgent` (`AudienceType.AzureAI` → Foundry agent from Lab 10) |
| `src/RailApp.tsx` | Two-panel layout |

## Unverified / to check

* `getNetworkSnapshot` relies on the Rayfin SDK supplying the OBO scope for `AudienceType.Kusto` and on that token being
  accepted by the Fabric KQL query endpoint. Test it with `npx rayfin dev` before a class.
* The Foundry REST call in `askRailAgent` (`POST {project}/openai/v1/responses` with `agent_reference`) is marked
  `TODO(verify)`. Check it against https://ai.azure.com/api-reference/responses/ for your API version.
* If functions aren't available in your tenant, use the Lab 08 dashboard for the map and the Foundry playground for chat.
