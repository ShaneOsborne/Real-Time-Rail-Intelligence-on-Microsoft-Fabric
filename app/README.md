# Rayfin app starter – map + "chat with the network" (Lab 11)

This folder is **not** a complete app. Rayfin projects are generated by the Rayfin CLI, so you scaffold
first and then copy the overlay files from `rayfin-starter/` into the generated project.

> Status (Oct 2026, Rayfin SDK ~1.34 / CLI ~1.33): Fabric Apps is **preview**; **connectors are preview**
> (the `kusto` connector type is marked *private preview*); **functions and delegated auth are experimental**
> and not available in every tenant/region. Check https://rayfin.ai/docs before you start.

## Steps (all commands are from the Rayfin docs)

```bash
# 1. Scaffold (Node.js 20+). Workspace = the Fabric workspace from Lab 02.
npm create @microsoft/rayfin@latest -- rail-app --workspace <workspacename>
cd rail-app
npx rayfin login

# 2. KQL connector to the Eventhouse database (delegated auth only)
npx rayfin connector add --type kusto --workspace-id <workspace-id> --item-id <kql-database-item-id> --name rail
#    -> run the pinned `npm install ...` command the CLI prints. Do NOT edit rayfin/connectors/rail/schema.ts.

# 3. (Experimental) functions for the chat panel
npx rayfin functions init

# 4. Copy the overlay files
cp -r ../app/rayfin-starter/src/* src/
#    merge ../app/rayfin-starter/rayfin/functions/src/function_app.ts into rayfin/functions/src/function_app.ts
#    then render <RailApp /> from your root component (e.g. src/App.tsx)

# 5. Deploy the backend and run the frontend locally
npx rayfin up                       # or: npx rayfin up --exclude-services staticHosting && npm run dev
npx rayfin dev                      # starts the local frontend dev server and deploys the backend

# 6. Test the connector from the CLI (needs a deployed backend)
npx rayfin connector invoke rail executeQuery --input '{"query":"NetworkSnapshot(1h) | take 5"}'

# 7. Ship
npx rayfin up --dry-run
npx rayfin up
npx rayfin up status
```

## What each overlay file does

| File | Purpose |
|---|---|
| `src/services/rayfinClient.ts` | `ConnectorsRayfinClient` wired to the `rail` Kusto connector (+ functions schema) |
| `src/features/network/loadSnapshot.ts` | Runs `NetworkSnapshot(1h)` via `executeQuery`, normalises with `toQueryResult` |
| `src/features/network/NetworkMap.tsx` | Dependency-free SVG map of GB, coloured by delay, refreshes every 30 s |
| `src/features/chat/ChatPanel.tsx` | Chat UI calling `client.functions.askRailAgent.invoke()` |
| `rayfin/functions/src/function_app.ts` | `askRailAgent` function: OBO token (`AudienceType.AzureAI`) → Foundry agent (Lab 10) |
| `src/RailApp.tsx` | Two-panel layout |
