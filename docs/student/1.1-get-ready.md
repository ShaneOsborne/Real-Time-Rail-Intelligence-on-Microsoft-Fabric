# Student 1.1 – Get ready

**Time:** 20 minutes · **Previous:** [Student path](README.md) · **Next:** [Student 1.2](1.2-fabric-workspace.md)

## Objectives

Check your Fabric access, install the tools and set up your copy of the repo. Your instructor has the NROD, RDM, Azure and
Key Vault set-up covered, so you don't need those accounts.

## Before you start

Get your **handout** from the instructor. It has your workspace name, the Event Hubs namespace, key name and key, **your own
consumer group**, the reference Lakehouse location and the Foundry details. Keep the key private.
(If the handout says **Workspace identity** instead of a key, there's no key: see [Student 1.4](1.4-connect-to-the-class-feed.md).)

## 1. Fabric access

Sign in to <https://app.fabric.microsoft.com>. Open your workspace from the handout (or check you can create one on the
class capacity). Confirm **+ New item** lists *Eventhouse*, *Eventstream* and *Lakehouse*.

## 2. Tools

Python 3.11+, Git and the Azure CLI (`az login` as yourself – you don't need an Azure subscription, only your work account).
Node.js 20+ and Azure Functions Core Tools if you'll do Lab 2.8. Docker and Power BI Desktop aren't needed (Labs 2.3 and 2.7
have web-only routes; Desktop is optional and Windows only).

Several of these need **admin rights or `sudo`** to install. The table in
[Solo 1.1 §6](../solo/1.1-prerequisites.md#6-tools-on-your-machine) lists which ones, and the alternatives without admin
rights. Install them before the class, or tell your instructor.

Check what you have:

```bash
az version
python --version          # 3.11+
git --version
node --version            # v20, v22 or v24 (Lab 2.8 only)
```

## 3. Clone the repo and configure

```bash
git clone https://github.com/<you>/rail-fabric-rti.git
cd rail-fabric-rti
cp .env.example .env     # then edit .env
az login
```

### Settings for your `.env`

```bash
FABRIC_WORKSPACE_NAME=rail-rti-student07   # from the handout
FABRIC_WORKSPACE_ID=                       # from the handout if the instructor created the workspace, else leave empty
FABRIC_CAPACITY_ID=                        # only if you create the workspace yourself (ask the instructor)
KUSTO_QUERY_URI=                           # printed by Student 1.2
FOUNDRY_PROJECT_ENDPOINT=                  # from the handout
FOUNDRY_MODEL_DEPLOYMENT_NAME=             # from the handout
FOUNDRY_AGENT_NAME=rail-network-agent-student07
```

Leave the `NROD_*`, `RDM_*`, `AZ_*`, `KEY_VAULT_*` and `EVENTHUB_*` values empty. The Event Hubs key goes into the
Eventstream source in the portal, not into `.env` (key sign-in only; with workspace identity there's no key).

## Checkpoint

- [ ] You can open (or create) your workspace and **+ New item** lists *Eventhouse*, *Eventstream* and *Lakehouse*
- [ ] `az version`, `python --version` (3.11+) and `git --version` work
- [ ] `.env` has your workspace name and the Foundry values from the handout
