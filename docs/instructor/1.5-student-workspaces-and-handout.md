# Instructor 1.5 – Student workspaces, Foundry access and the handout

**Time:** 30 minutes · **Previous:** [Instructor 1.4](1.4-shared-event-hub.md) · **Next:** [Instructor 1.6](1.6-running-the-class.md)

## 1. Student workspaces (optional but recommended)

Either let students create their own in [Student 1.2](../student/1.2-fabric-workspace.md) (they need permission to assign
workspaces to the capacity: *Capacity settings → Contributor permissions*), or create them for them:

```bash
# One workspace per student, with the empty items; then add the student as Admin in the portal (Manage access)
for n in 01 02 03; do
  FABRIC_WORKSPACE_ID= FABRIC_WORKSPACE_NAME="rail-rti-student$n" ./scripts/fabric-setup.sh
done
```

Variables set on the command line win over `.env`. Note each workspace ID for the handout.

Set **workspace-level surge protection** limits on each student workspace, so one student can't starve the others
([classroom sizing](1.4-shared-event-hub.md#classroom-sizing-fabric-capacity)).

## 2. Consumer groups

Each student needs **their own** consumer group on both hubs (`student01`, `student02` …). `create-eventhub` made them in
Instructor 1.4. To add more, see [Instructor 1.4, Option A step 3](1.4-shared-event-hub.md#option-a--automated-instructor).

## 3. Foundry access for students

In the shared Foundry project (Instructor 1.1):

* Give every student **Foundry User**.
* Adding the **Fabric IQ** tool creates a project connection and needs **Foundry Project Manager**. Either give students that
  role, or add the tool for each student's data agent yourself (Lab 2.6, step 3).
* Each student uses **their own** agent name, for example `rail-network-agent-student07`, so agents don't clash in the shared project.

## 4. Azure Maps for Lab 2.9 (optional)

If the class does the optional [Lab 2.9](../build/2.9-azure-maps.md):

1. Do Lab 2.9 **steps 1–2** once for the class (or once per student): the Azure Maps account, and the railway-lines file
   committed to the repo. Add each student's app URL to `AZURE_MAPS_ALLOWED_ORIGINS`.
2. Each day of the class, create a token with `./scripts/new-azure-maps-sas.sh` (Lab 2.9, step 4) and give it to the
   students. It expires within 24 hours. Students do steps 3–6 with it.
