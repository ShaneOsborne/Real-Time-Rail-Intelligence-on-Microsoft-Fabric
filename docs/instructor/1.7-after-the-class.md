# Instructor 1.7 – After the class

**Time:** 15 minutes · **Previous:** [Instructor 1.6](1.6-running-the-class.md) · **Next:** [Lab 2.1](../build/2.1-kql-transformations.md) (Part 2, for your next run-through)

1. **Students** run the *Classroom students* section of [Lab 2.10](../build/2.10-cleanup.md): they deactivate
   their Eventstreams, delete their Foundry agent and Rayfin app, and delete their workspace. If a student's workspace is
   kept, make sure its Event Hubs sources are deleted or deactivated.
2. **Rotate the `students-listen` key**, or delete the namespace (below). The key works on every consumer group, so rotate it
   even if you keep the namespace:

   ```bash
   az eventhubs namespace authorization-rule keys renew -g rg-rail-fabric-rti --namespace-name <namespace> --authorization-rule-name students-listen --key PrimaryKey
   ```

   This only applies to key sign-in. **With `EVENTHUB_AUTH=entra`** there's no key to rotate. Remove the students'
   **Azure Event Hubs Data Receiver** roles instead, unless you delete the namespace:

   ```bash
   ./scripts/grant-eventhub-reader.sh --id <student01 ID> --id <student02 ID> --remove
   # PowerShell: ./scripts/grant-eventhub-reader.ps1 -Id '<student01 ID>','<student02 ID>' -Remove
   ```

   If a student has already deleted their workspace, its identity is gone too. Remove any leftover role assignment in the
   namespace → **Access control (IAM)** → **Role assignments**.

3. Run [Lab 2.10](../build/2.10-cleanup.md) in full for your own resources, and **scale the capacity back down** to its
   normal size, or pause it.
4. **Foundry:** remove **Foundry User** (and **Foundry Project Manager**, if you gave it) from students if the project stays.
   Delete any agents students left behind in the shared project.
5. Remove the student security group from the tenant settings if it was only for this class.
6. Delete the `handouts/` folder that `make-handouts` created. It can contain the old key.

## Shared Event Hub clean-up

The namespace lives in `AZ_RESOURCE_GROUP`, so [Lab 2.10](../build/2.10-cleanup.md) removes it with everything else. To remove only the shared tier and keep the rest:

```bash
az eventhubs namespace delete -g rg-rail-fabric-rti -n <namespace>
BRIDGE_TARGET=eventstream DEPLOY_RDM_RELAY=false ./scripts/deploy-bridge.sh   # back to the direct path
az containerapp delete -g rg-rail-fabric-rti -n ${NAME_PREFIX:-railrti}-rdm-relay --yes
az containerapp delete -g rg-rail-fabric-rti -n ${NAME_PREFIX:-railrti}-darwin-relay --yes   # only if you ran the Darwin class feed
```

- [ ] The capacity is back to its normal size, or paused
